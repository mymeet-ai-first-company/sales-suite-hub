Как работает

Один поток от звонка до договорённостей.

Никаких ссылок для бота и новых привычек перед встречей. Desktop появляется в нужный момент и сам доводит запись до mymeet.ai.

01

Замечает звонок

Распознаёт Zoom, Teams, Meet и другие приложения, когда они начинают использовать микрофон.

02

Записывает обе стороны

Системный звук сохраняет собеседников, микрофон — ваш голос. Файл остаётся на компьютере.

03

Возвращает результат

После остановки встреча появляется в workspace вместе с транскриптом, саммари и договорённостями.

Без бота

Записывать там, где лишний участник мешает.

Внешний звонок, приватный разговор, интервью или встреча в нативном приложении — Desktop остаётся на компьютере и не входит в созвон.

Не менять состав встречи. Участники видят только друг друга.
Не зависеть от платформы. Записывать любой звонок с системным звуком.
Не терять запись. Локальная очередь продолжит загрузку после восстановления сети.

Первый запуск

Установить без сюрпризов.

Для каждой системы — короткий маршрут. Разрешения нужны только для записи вашего голоса и звука встречи.

mymeet.ai для macOS

Сборка подписана Developer ID и нотариализована Apple. Система проверит приложение при первом запуске.

Выбрать версию Mac
1. Открыть DMG

Скачать версию для Apple Silicon или Intel и открыть установочный файл.

2. Перенести в Applications

Перетащить mymeet.ai в папку Applications и запустить приложение.

3. Войти через браузер

Desktop откроет авторизацию mymeet.ai и сохранит выбранный workspace.

Надёжность

Не зависеть от качества интернета.

FAQ

Разобраться, если что-то не сработало.

Короткие ответы на частые вопросы. Для сложного случая напишите в поддержку и приложите версию приложения.

Как понять, какой Mac-установщик скачать?
Откройте меню Apple → «Об этом Mac». Если в строке Chip указано Apple M1, M2, M3 или M4, выбирайте Mac Silicon. Для Mac с процессором Intel скачайте Mac Intel.
Не появилось уведомление о звонке
Запустите запись вручную из окна Desktop или tray-меню. Если приложение звонка редкое, пришлите его название в поддержку.
Запись получилась пустой
Проверьте системные разрешения для микрофона и записи системного аудио, затем полностью перезапустите mymeet.ai Desktop.
Windows показывает Unknown publisher
Нажмите More info → Run anyway и продолжите установку. После установки приложение запускается обычным способом из tray.
Где появятся транскрипт и саммари?
После остановки запись загрузится в выбранный workspace. Встреча появится вместе с транскриптом и саммари.
Где посмотреть предыдущие версии?
Все сборки и заметки к релизам доступны на странице релизов GitHub.
